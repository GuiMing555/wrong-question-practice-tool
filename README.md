# 考试题本与错题循环练习工具

这个项目源于实际刷题时遇到的问题：一些已经购买的题库没有完善的错题重复练习逻辑，也不支持将错题导出保存。工具把截图识别、整理出的完整练习集合称为“题本”；只有在练习应用中实际答错或点击“我不会”的题目才进入“错题本”。

项目由两个独立应用组成。升学考试题本与截图整理工具联动；公务员考试使用单独的人工录入题库，不读取截图数据库：

- **错题每日自动化整理**：截取指定窗口，使用 macOS Vision 识别文字，整理完整题本工作簿，并可按设置生成可打印的 Word 文档。
- **考试题本练习**：主界面提供升学考试和公务员考试入口，按科目或行测分类进行普通练习和错题练习；逐题保存作答状态，中途退出时自动结束本轮练习。

macOS Apple 芯片用户可从 [Latest Release](https://github.com/GuiMing555/medical-wrong-question-suite/releases/latest) 下载同时包含两款应用的最新 DMG。

目前 macOS 版本可以构建使用。Windows 目录是早期迁移原型，尚未同步本版本功能，不能视为可用的 Windows 发行版。

## 适用范围

当前版本主要围绕医学综合题目开发和测试，但识别、查重、导出及循环练习流程本身并不依赖特定医学知识。对于政治、法律等以固定选项的单选题、多选题和现成解析为主的科目，理论上也有适配的可能。

不同题库的页面版式、选项标记和解析结构可能存在差异，目前没有对这些科目及各类平台逐一验证，因此不能保证直接使用时都能正确识别；必要时可能需要针对具体版式调整解析规则。

## 1.3.0 更新内容

- 练习应用改为考试目录主页，升学考试包含医学综合、政治、英语三个独立科目，公务员考试预留行测、申论和面试入口。
- 新增升学考试动态计划：按结束日期、三科题量、旧题复习和预计错题量动态分配每日任务；英语后置且每日最多分配 30 题。
- 错题模式按每道错题三次展开，并以动态间距打乱，避免同一道题连续或短间隔出现；达到设定连续答对次数后移出错题本。
- 选项圆圈用于作答，点击选项文字可排除或取消排除；题目页显示完成百分比，并支持可调阈值的双指实时翻页动画和已答题回看。
- 新增政治论述题：输入文字答案后可交给用户配置的兼容接口评分，保存各考点判断、分数及评语；点击“我不会”仍直接进入错题本。
- 截图工具优先读取已绑定浏览器窗口的页面文字，数据完整时不保留截图；失败时回退本机 OCR。整理过程增加进度窗口、三次重试上限和可复制失败原因。
- 医学综合、政治、英语分别生成独立题本和工作簿；累计答错次数、累计作答次数、错题本状态随每次提交实时更新。
- 新增题目分析回复数据库、当日新增知识点和当前错题知识点 Word；访问接口是可选功能，默认关闭且不预置服务地址、模型或访问密钥。
- 两个应用加入单实例保护，避免同一台机器重复运行同一应用。

## 主要功能

- 默认单独轻点右侧 Shift 采集当前题，也可以在设置中更换快捷键。绑定 Chrome 题库窗口后优先直接读取页面数据；题干、选项、答案和解析校验通过时只保存文字，不生成图片。
- 采集时不需要选择科目。整理程序会根据题干和选项自动区分医学综合、政治、英语，并分别写入三个独立题本；英语优先使用题干语言及固定章节特征，中文题重点区分政治与医学。无法可靠判断的题保留为待校对，不会默认塞进某个题本。
- 可指定采集文件保存目录、整理文件输出目录和目标窗口。
- 默认使用“焚题库专项识别”，针对当前题库的页面范围、标题杂字和常见医学字符优化；设置中可切换为“通用识别”，供其他版式使用。
- 直接读取失败或内容不完整时，才回退保存窗口图像，并使用系统自带的 Vision 框架在本机识别；图片不上传。
- 每日定时整理错题，默认执行时间为 15:00。
- 始终生成可筛选、可编辑的题本工作簿；工作簿包含固定医学分类、题干、选项、答案、解析、当前错题本状态、累计答错次数和累计作答次数。
- 练习应用每提交一道题就先写入共享数据库，再刷新工作簿中的实时统计；意外退出不会丢失本次作答记录。
- 可选生成纯题、答案与解析、知识点背诵汇总三份固定格式 DOCX 文档；该选项默认关闭。
- 可在独立的“API 设置”页面启用题目分析 API、填写接口地址、模型和访问密钥并测试连接。整理时弹出进度窗口；单题连续失败 3 次后停止重试，并返回可复制的逐次失败原因。
- 自动按题干查重；连续截到同一道题视为误操作，不累计错误次数。
- 同一道题有时间间隔地重复出现时累计次数，达到 2 次后标红并显示计数。
- 无答案、无解析、选项不全或重复截图等记录会复制到待校对目录，并在文件名前注明原因。
- 截图整理工具和练习工具共用本地数据库。识别出的完整题目进入“题本”，不会因为被截图而自动加入“错题本”；只有实际答错或点击“我不会”才写入错题本。

## 练习模式

主界面先选择“升学考试”或“公务员考试”。升学考试包含医学综合、政治、英语三个科目，每科分别拥有独立的题本、错题本和作答记录。公务员考试包含行测、申论、面试；行测代码支持政治理论与常识判断、言语理解与表达、数量关系、判断推理、资料分析五大分类，申论和面试暂时只保留入口。

三个升学科目及行测五大分类均提供普通模式和错题模式。普通模式会选取从未作答或超过设定复习间隔的题目，并打乱题目和选项顺序。错题模式只练习当前题本的错题；连续答对达到设定次数后，题目会自动移出对应错题本。

每次提交都会立即写入数据库。练习错题本只记录实际答错或点击“我不会”的题目，不会因为题目来自截图而自动加入。单选题选中正确答案后自动进入下一题；答错时显示解析。多选题需要手动提交，答错后停留在当前题。所有题型都提供独立的“我不会”选项，点击后直接加入错题本并显示正确选项和解析。

退出答题页时，本轮练习自动交卷，不在主页保留“继续练习”入口。已经提交的题目保持原有记录，尚未作答的题目不会被判错，之后仍可通过普通模式重新抽取。

一轮练习结束前，可使用触控板双指左右滑动回看已答题。题目页会跟随手势实时移动，松手后翻页或回弹；翻页触发距离可在设置中调整。回看时保留上次选择、正误结果、正确选项和解析。

医学综合继续使用原数据库，政治和英语分别使用独立数据库：

```text
~/Library/Application Support/医学综合练习/question-bank.sqlite3
~/Library/Application Support/考试题本练习/政治/question-bank.sqlite3
~/Library/Application Support/考试题本练习/英语/question-bank.sqlite3
~/Library/Application Support/考试题本练习/公务员考试/行测/<行测分类>/question-bank.sqlite3
```

公务员行测题库与截图识别、自动科目分类和升学考试数据库完全隔离，五类数据库分别保存作答状态。出于题库权利和个人数据边界，公开源码与公开 DMG 不附带题目、解析或图片；只有自行提供符合导入格式的数据包后，行测入口才可实际练习。

## 整理输出

每日整理始终生成：

- `医学综合题本.xlsx`
- `政治题本.xlsx`
- `英语题本.xlsx`

设置中开启“生成可打印 Word 文档”后，再生成：

- `医学综合题本_纯题.docx`
- `医学综合题本_答案与解析.docx`
- `政治题本_纯题.docx`
- `政治题本_答案与解析.docx`
- `英语题本_纯题.docx`
- `英语题本_答案与解析.docx`
- `医学综合知识点背诵汇总.docx`（存在题目分析结果时）

所有截图都按需要复习的内容处理，不根据页面显示的答对或答错状态过滤。程序只根据截图中实际存在的题干、选项、答案和解析整理内容；无法可靠识别的信息会标记为待校对。

题目分析 API 目前使用医学综合四部分分类、政治三部分分类，以及英语的语音、语法与词汇、完形填空、阅读理解、对话、写作六类。分类必须落在固定表内；本地规则只在接口关闭时作为科目兜底。启用接口后以接口返回的固定分类为准，失败会自动重试，连续三次失败后在进度窗口保留可复制的具体原因并标记待校对。

## 构建 macOS 应用

环境要求：

- macOS 13 或更高版本
- Xcode Command Line Tools
- Swift 5.9 或更高版本

仅构建：

```bash
./script/build_and_run.sh --build-only
```

公开构建不需要也不会读取任何代码签名证书，应用仅使用临时签名。若开发者拥有可以合法分发的行测数据，可在本机指定原始四列表格导出；该文件只用于本次构建，不会被加入 Git：

```bash
CIVIL_SERVICE_BANK_SOURCE=/绝对路径/questions.jsonl ./script/build_and_run.sh --build-only
```

构建后的应用位于 `dist/`。构建并启动两个应用：

```bash
./script/build_and_run.sh
```

安装到 `/Applications` 并验证进程：

```bash
./script/build_and_run.sh --install-verify
```

打包同时包含两款应用的 DMG：

```bash
./script/package_dmg.sh 1.3.0
```

运行测试：

```bash
swift test
```

## macOS 权限

首次使用全局快捷键时，需要在“系统设置 → 隐私与安全性 → 辅助功能”中授权。只有页面数据不完整、需要回退截图时，才需要允许“屏幕与系统音频录制”。授权后请退出并重新打开应用。

每日整理使用当前用户的 LaunchAgent 执行，设置窗口无需保持打开。

## 隐私

应用不读取浏览器账号、密码或 Cookie。截图识别、查重、作答记录和工作簿整理均在本机完成，题目分析 API 默认关闭，服务地址、模型和访问密钥均为空。用户主动配置并启用后，程序只向所填写的接口逐题提交题干、选项、已知答案和解析文字，不上传截图；访问密钥不加密，保存在应用支持目录下仅当前账户可读写的本地权限文件中，不调用钥匙串。

源码仓库和公开 DMG 均不包含用户截图、本地数据库、生成文档、访问密钥、题库数据、开发者证书、私钥或描述文件。发布前会对源码、历史提交和安装包进行敏感信息扫描。

## 当前局限性

- 当前正式版本仅面向 macOS 13 及以上的 Apple 芯片设备。`Windows/` 是未同步当前功能的早期原型，尚未完成 Windows 构建和验收。
- 公开 DMG 使用临时签名，没有使用 Apple Developer 证书，也未经过 Apple 公证。首次打开可能出现系统安全提示；版本更新后，辅助功能或屏幕录制权限可能需要重新授权。
- 公开版本不提供任何题库内容。用户需要通过自己的合法来源截图整理，或自行准备符合接口约定的数据包；公务员行测、申论和面试因此不能开箱即用。
- 浏览器页面直读目前主要针对 Chrome 和已经适配的题库版式。页面结构、懒加载、隐藏解析或站点更新都可能导致字段不完整，此时会回退 OCR 或进入待人工校对。
- OCR、自动科目分类和题干查重均无法保证百分之百准确。政治与医学的中文题在信息不足时尤其可能无法可靠区分，程序会尽量保留为待校对而不是强行入库。
- 题目分析、无解析补全、知识点整理和论述题评分依赖用户自行配置的兼容接口及网络服务；接口输出仍可能不准确，论述题得分只能作为练习反馈，不能替代正式阅卷。
- API 密钥目前保存在本机权限为 `0600` 的普通文件中，没有使用钥匙串加密。共享电脑用户应自行评估是否启用，并定期更换密钥。
- 定时整理依赖当前登录用户的 LaunchAgent；电脑关机、休眠或账号未登录时，不能保证在设定时刻执行。
